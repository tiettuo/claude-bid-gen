## 二、成本建模（新增发现 — 10 轮研究未覆盖）

### 2.1 单项目成本拆解

| 步骤 | 调用次数 | 输入 tokens | 输出 tokens | 费用 |
|------|:---:|------:|------:|------:|
| 骨架抽取 | 1 | 15,000 | 3,000 | $0.016 |
| brain 翻译 | 1 | 8,000 | 5,000 | $0.017 |
| plan 合成 | 1 | 12,000 | 4,000 | $0.017 |
| rules 合成 | 1 | 10,000 | 6,000 | $0.020 |
| 难点分析 | 1 | 5,000 | 2,000 | $0.004 |
| **章节生成** | **12** | **60,000** | **24,000** | **$0.094** |
| **审校** | **12** | **96,000** | **12,000** | **$0.086** |
| 格式审计 | 1 | 5,000 | 500 | $0.002 |
| **合计** | | | | **$0.256** |

- 批量(10 variants): ~$2.56
- **Kimi 占成本 97.9%** — 审校成本几乎等于写作成本

### 2.2 成本优化方案

| 方案 | 节省/项目 | 新单项目成本 | 风险 |
|------|:---:|------:|------|
| A: review 切 deepseek | $0.047 (18%) | $0.208 | 审校质量可能下降 |
| B: writing 全切 deepseek | $0.051 (20%) | $0.205 | R4/R5 确认 DS 写作弱于 Kimi |
| C: 混合 writing (Kimi 6关键章 + DS 6制度章) | $0.026 (10%) | $0.230 | 制度章本就是质量洼地，换模型影响小 |
| **推荐: A+C 组合** | **$0.073 (28%)** | **$0.183** | 风险可控 |

### 2.3 关键洞察

> **审校成本 ($0.086) 几乎等于写作成本 ($0.094)。这是最大的成本异常。**

审校的 input tokens (96K = 12章×8K) 极高，因为每章审校都要输入原文全文。
优化方向：审校不应逐章独立调用，应做一次性批量审校（12章 → 1次调用），将 12 次 input 的重复开销消除。

## 四、10 轮研究盲区识别

以下维度在 R1-R10 中提及但未深入研究：

### 4.1 盲区一：审校系统的根本性重构

R1 发现审校 issues 为空，R4 引入三维评分，但**审校架构本身的问题未被质疑**：
- 当前：逐章独立审校（12 次 LLM 调用，成本高、无跨章视角）
- 应做：批量审校 + 跨章一致性检查 + 规则引擎前置过滤
- 成本：这是最大的优化空间（见上）

### 4.2 盲区二：项目针对性量化

R3 提到「体量 vs 密度」悖论，深评报告提到「模板化套话」，但：
- 未建立「废话率」的量化指标
- 未探索 writer prompt 注入 project_brain 第三/四节（重点+难点）对质量的提升效果
- 未做 A/B 测试

### 4.3 盲区三：知识管理的进化路径

P2.1 提出了 SQLite FTS5 方案，但：
- 未评估现代向量数据库（ChromaDB / FAISS / Milvus）
- 未探索 RAG 混合检索（关键词 + 语义）
- 19 条 memory 文件呈线性增长，缺乏自动去重/合并/冲突检测

### 4.4 盲区四：架构演进 — Pipeline → Agent

当前架构是严格的线性 Pipeline，但：
- Step 2 失败需要从头手写 → 缺少自动恢复
- review → rewrite 循环只有 2 次 → 缺少自适应重试策略
- 各步骤之间没有反馈信号 → 缺少「下游发现的问题反馈上游」

探索方向：基于 Agent 的架构，各步骤作为工具暴露给一个编排 Agent，由 Agent 根据中间结果动态决策下一步。

### 4.5 盲区五：实际中标数据验证

R10 的「未知/待验证」清单包括：
- 实际评标得分（需要真实中标数据）
- 跨项目内容串用检测

这两项仍然缺失。建议：与用户合作收集 3-5 个真实项目的中标/落标数据，建立反馈回路。

## 五、v4 路线图纠偏建议

### 🔴 新增 P0.8：审校系统重构（替代原 P1.1）

|------|------|------|

## 七、结论

bid-gen 的**设计骨架正确**（10 轮研究 + 竞品分析双重验证），当前**赛道窗口明确**（1-2 年无直接竞品），最大短板已从「设计理念」转向「执行一致性」和「成本效率」。

1. 审校系统从「单维字数检查」升级为「四维质量保障」
2. 项目针对性从「通用模板」升级为「brain 驱动」
3. 成本从「$0.26/项目」优化到「$0.13/项目」
