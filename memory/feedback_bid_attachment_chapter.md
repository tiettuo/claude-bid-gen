---
name: 附图附表必须集中在专属章节
description: 招标大纲规定的"附图及附表"章节是评委逐条核对的锚点，所有附图必须放在该章节里，不能散落到正文章节
type: feedback
---
当招标文件施工组织设计大纲（"投标文件构成 / 编制要求"等章节）里明确列出"第N章 附图及附表"并枚举附表一、附表二…附表X时：

**所有附图（施工总平面图、施工进度网络图等）必须集中嵌入该专属章节**，按附表编号顺序排列；正文相关章节（如施工总平面布置、施工总进度计划）只能用文字描述 + "详见第 N 章附表 X"跳转引用，**不得在正文章节内嵌图**。

**Why:** 评委在合格制评审时按招标大纲的附表清单逐条核查"附表X 是否存在"。图放在错误的章节 = 评委在第 N 章看不到 = 视为"附表缺失" = 不响应实质性要求 = 不合格。即使图渲染再漂亮也不计数。仓储类项目A曾把 site_layout 图放第 6 章，被用户指出必须移到第 15 章附表五。

**How to apply:**
1. Step 2 生成 chapter_plan 时，"附图及附表"章节子项必须 1:1 抄录招标大纲的附表清单（附表一/二/三/四/五…），**不可漏附表**
2. 该章节所有附表对应的 chart JSON（schedule / site_layout / org_chart 等）只能放在这一章的 md 文件里
3. 正文章节涉及该图主题时，用"详见第N章附表X"代替内嵌
4. bid_chart_specs 自动生成 chart_specs 时，required 图必须把目标章节定位到"附图及附表"章节，不能按主题章节默认推断
